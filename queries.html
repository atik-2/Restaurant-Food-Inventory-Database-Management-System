Q1b. Discount baad diye asol price

Admin panel-e discount set kora hoy, customer panel-e ei query diyei kom dam ta dekhano hoy. Calculated column — database-e alada kore rakha hoy na, proti bar hisheb kore neya hoy.

SELECT name, price, discount,
       ROUND(price - (price * discount / 100), 2) AS final_price
FROM menu_items
WHERE discount > 0
ORDER BY discount DESC;

Q7. LEFT JOIN — all customers, even without any order

LEFT JOIN keeps every row of the left table. A customer with no order still appears, with count 0.

SELECT c.name, COUNT(o.order_id) AS total_orders
FROM customers c
LEFT JOIN orders o ON c.customer_id = o.customer_id
GROUP BY c.customer_id, c.name;

Q8. Bill of one order (4 tables joined)

This one query produces a complete customer bill.

SELECT o.order_id, c.name AS customer, m.name AS item,
       oi.quantity, oi.price, (oi.quantity * oi.price) AS subtotal
FROM orders o
JOIN customers   c  ON o.customer_id = c.customer_id
JOIN order_items oi ON o.order_id    = oi.order_id
JOIN menu_items  m  ON oi.menu_id    = m.menu_id
WHERE o.order_id = 1;

Output

order_idcustomeritemquantitypricesubtotal
1Rahim UddinChicken Biryani2280.00560.00
1Rahim UddinMilk Tea140.0040.00

Total bill = 600.00

Q10. Daily sales report

GROUP BY makes one row per day; SUM and COUNT are aggregate functions.

SELECT DATE(order_date) AS day,
       COUNT(*) AS total_orders,
       SUM(total_amount) AS total_sales
FROM orders
WHERE status = 'Paid'
GROUP BY DATE(order_date)
ORDER BY day;

Output

Q12. Purchase cost per supplier (GROUP BY + HAVING)

WHERE filters rows, HAVING filters groups after grouping. Spice Bazar (4125.00) is removed here.

SELECT s.name, SUM(p.cost) AS total_cost
FROM suppliers s
JOIN purchases p ON s.supplier_id = p.supplier_id
GROUP BY s.supplier_id, s.name
HAVING SUM(p.cost) > 5000
ORDER BY total_cost DESC;

Output

nametotal_cost
Meat House BD16850.00
Daily Dairy10300.00
Fresh Farm Ltd6450.00

Q13. Items priced above the average (SUBQUERY)

The inner query runs first and gives one value (average price = 172.86), then the outer query uses it.

SELECT name, price
FROM menu_items
WHERE price > (SELECT AVG(price) FROM menu_items);

Q14. Employee wise sales

IFNULL shows 0 instead of NULL for employees who handled no order.

SELECT e.name, e.role, COUNT(o.order_id) AS orders_handled,
       IFNULL(SUM(o.total_amount), 0) AS sales
FROM employees e
LEFT JOIN orders o ON e.employee_id = o.employee_id
GROUP BY e.employee_id, e.name, e.role
ORDER BY sales DESC;
